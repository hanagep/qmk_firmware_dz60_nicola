# DZ60 Nicola Keymap

このキーマップは、US配列の物理レイアウトを維持しつつ、日本語OS設定でのUS配列エミュレーション機能や親指シフト（Nicola）入力を統合した特別なキーマップです。

## 特徴

### 1. 二つのベースモード
`FN + 左ctrl` キーで以下の2つのモードを切り替えることができます。

*   **通常USモード (Blue LED)**: 物理刻印通りのUS配列として動作します（OS側がUS配列設定の場合に最適）。
*   **JP互換エミュレーションモード (Green LED)**: **OS側が日本語配列設定のまま**でも、US配列の刻印通りに記号（@, #, ^, &, (, ), [, ], \ 等）を入力できるエミュレーションモードです。

### 2. 親指シフト (Nicola) 入力とIME操作
split spacebarレイアウトを想定。その間のキーをFNとする。

*   **FNキー (タップダンス)**:
    *   **シングルタップ**: 英数入力モード（IME OFF + Nicola OFF）
    *   **ダブルタップ**: Nicola日本語入力モード（IME ON + Nicola ON）
    *   **長押し**: FNレイヤー
*   **FNキーの左右キー**: スペースキーとして機能します。
*   **親指シフトキー (Nicolaモード時)**: 左右どちらのシフトキーも単独で打鍵するとスペースが入力されます。

### 3. LEDによるステータス表示
現在のモードを一目で判別できるよう、LEDの色が変化します。

| モード | LED色 |
| :--- | :--- |
| 通常USモード (初期値) | 青 (Blue) |
| JP互換エミュレーション | 緑 (Green) |
| Nicolaモード単体 | 赤 (Red) |
| JP互換 + Nicola | 紫 (Purple) |

### 4 キー移動
#### 【左手】ナビゲーション（ESDFカーソル）
*   **E / S / D / F:** カーソルキー（上 / 左 / 下 / 右）
*   **W / R:** Home / End

#### 【右手】ナビゲーション（JKLM周辺）
*   **J / K:** Insert / Home
*   **L / ;:** PageUp / BackSpace (1文字削除)
*   **M / , / .:** Delete / End / PageDown


### 5. 便利マクロ
特定の操作を効率化するためのマクロを搭載しています。

*   **ディスプレイ移動**: `KC_SPC` 右横のキー。 Windows + Shift + → (100ms待機付きで確実な動作)
*   **Teamsミュート**: ディスプレイ移動キーのさらに右。 Windows + Alt + K (100ms待機付き)
*   **ファームウェア書き込み**: `FN + Backspace` でブートローダーモードに移行します（物理ボタン操作不要）。
*   **VS Code markdown preview**: `FN + B` でVS Code上でMarkDownのPreview表示。


## ビルド方法
QMKリポジトリのルートで以下のコマンドを実行します。

```bash
qmk compile -kb dz60 -km nicola
```
